# SRT Express Projects

เว็บไซต์ต้นแบบเพื่อการศึกษา สำหรับบริการขนส่งสินค้าห่อวัตถุด่วนของการรถไฟแห่งประเทศไทย โดยเน้นแนวคิดการส่งข้ามสาย การประเมินค่าระวาง และการดูแลสินค้าตลอดการขนส่ง

## ความสามารถหลัก

- คำนวณราคา SRT Express One Price ภายในสายเดียวกัน 70 บาทต่อชิ้น และข้ามสาย 100 บาทต่อชิ้น
- ตรวจเกณฑ์น้ำหนักไม่เกิน 2 กิโลกรัม และขนาดแต่ละด้านไม่เกิน 50 เซนติเมตร
- พิมพ์ค้นหาสถานีต้นทางและปลายทางได้จากชื่อหรือรหัสย่อ โดยแสดงสถานี 444 แห่งทั่วประเทศ และตัดที่หยุดรถ/ป้ายหยุดรถออกจากรายการรับฝาก
- เมื่อเกิน One Price ระบบคำนวณงบประมาณจากระยะทาง น้ำหนักปัดขึ้น อัตราด่วน 2 เท่า ค่าธรรมเนียมตามโครงสร้างเดิม 50% และขั้นต่ำ 60 บาทต่อชิ้น
- ผู้ใช้กรอกระยะทางที่สถานียืนยันเองได้ หรือให้ระบบประมาณจากโครงข่ายและพิกัดสถานี
- แสดง Timeline ของทุกสถานีบนแนวเส้นทางที่ระบบจำลอง พร้อมระยะทางรายช่วง ระยะสะสม และจำนวนสถานี
- เส้นทางข้ามสายบังคับเชื่อมผ่านสถานีชุมทางบางซื่อ ซึ่งทำหน้าที่เป็นจุดศูนย์กลางของแบบจำลอง
- แยกค่าระวางออกจากค่ากล่องและค่าเดินทางของผู้ใช้
- แสดงแบบจำลองกรอบเวลา 24 ชั่วโมงสำหรับสายเดียวกัน และ 48 ชั่วโมงสำหรับเส้นทางข้ามสาย
- รองรับหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์
- พิมพ์ใบประเมินราคาได้จากเบราว์เซอร์
- แยกแกนคำนวณไว้ใน `assets/calculator-core.js` เพื่อให้ทดสอบสูตรได้โดยไม่พึ่งส่วนแสดงผล

## ระบบการออกแบบ

- ใช้แนวทาง UX เดียวกับโปรเจกต์ Netherlands Train Signalling เช่น Navbar โปร่งใสก่อนเลื่อนและเปลี่ยนเป็น Floating Liquid Glass Island หลังเลื่อนหน้า
- ปรับอัตลักษณ์ทั้งหมดเป็น SRT Express ด้วยสีแดงเลือดหมู สีทอง และกราฟิกรางรถไฟของโครงการนี้เอง
- รองรับ 3 โหมดสี ได้แก่ ตามระบบ สว่าง และมืด โดยใช้ storage key `srtx-theme` แยกจากเว็บไซต์ Netherlands
- ใช้พื้นผิว Liquid Glass แบบหลายชั้น พร้อม Spotlight ตามตำแหน่งเมาส์ Ripple เมื่อกด และ Smooth Reveal สำหรับผลลัพธ์/Timeline โดยเคารพการตั้งค่า Reduce Motion
- ปรับลำดับขนาดตัวอักษรของฟอร์ม หมายเหตุ รายละเอียดราคา และสถานีระหว่างทางให้อ่านง่ายบนทั้งมือถือและคอมพิวเตอร์
- ใช้ Google Sans สำหรับ H1, Navbar และ Footer, IBM Plex Sans Thai สำหรับหัวข้อ, Kanit สำหรับเนื้อหา และ IBM Plex Mono สำหรับตัวเลข
- โค้ด เนื้อหา assets และการตั้งค่าธีมของทั้งสองเว็บไซต์แยกจากกัน ไม่มีการอ้างไฟล์ข้าม repository

## ข้อมูลและสูตรอ้างอิง

- `assets/stations.js` สร้างจากชุดข้อมูลทะเบียนสถานีของการรถไฟแห่งประเทศไทย มี 684 ระเบียน รวมสถานี ที่หยุดรถ และป้ายหยุดรถ เพื่อใช้สร้างโครงข่ายเส้นทาง แต่ช่องต้นทาง–ปลายทางจะแสดงเฉพาะสถานี 444 แห่ง
- มีรหัสย่อสำหรับค้นหา 431 จาก 444 สถานีที่เลือกได้ ส่วนสถานีที่ยังจับคู่รหัสไม่ได้จะแสดงด้วยชื่อสถานีโดยไม่สร้างรหัสสมมติ
- ข้อมูลทางการมีพิกัดสถานี 436 ระเบียน อีก 247 ระเบียนใช้พิกัดกลางของจังหวัดเพื่อประมาณระยะทาง และสถานีปาดังเบซาร์เขต รฟม. ใช้พิกัดสถานีปาดังเบซาร์เขต รฟท. ที่อยู่ในกลุ่มเดียวกัน
- ลำดับสถานีใน Timeline สร้างจากโครงข่ายสายหลักและสายสาขาของทะเบียนสถานี โดยคำนวณเส้นทางสั้นสุดภายในสาย และบังคับผ่านชุมทางบางซื่อเมื่อข้ามสาย ระยะทางยังเป็นค่าประมาณ ไม่ใช่ระยะทางรับรองของ รฟท.
- ประมาณการนอก One Price ใช้สมการอัตราธรรมดาต่อกิโลกรัม `1.88 + 0.016 × ระยะทาง` ซึ่งสอบเทียบให้ตรงกับช่วง 391–410 กิโลเมตรที่อ่านได้จากใบแทรก 910 จากนั้นคิดอัตราด่วน 2 เท่า บวกค่าธรรมเนียมตามโครงสร้างเดิม 50% และใช้ขั้นต่ำ 60 บาทต่อชิ้น
- สมการข้างต้นเป็นแบบจำลองเพื่อวางงบประมาณ ไม่ใช่การถอดตารางใบแทรก 910 ครบทุกช่วง และไม่ยืนยันสถานะการใช้ในปัจจุบัน

แหล่งข้อมูล:

- [ชุดข้อมูลสถานีของ รฟท.](https://gdc.railway.co.th/dataset/after16)
- [รายการสถานีรถไฟในประเทศไทยสำหรับจับคู่รหัสย่อ](https://en.wikipedia.org/wiki/List_of_railway_stations_in_Thailand)
- [ชุดข้อมูลโครงข่ายรถไฟ กรมการขนส่งทางราง](https://datagov.mot.go.th/th/dataset/drt2568_09)
- [หน้าเอกสาร/แบบฟอร์ม รฟท. สำหรับใบแทรก 910](https://srtcontainer.railway.co.th/downloads.php)
- [ใบแทรก 910 ฉบับ PDF](https://srtcontainer.railway.co.th/docs/910.pdf)

## การเปิดใช้งาน

เปิดไฟล์ `index.html` โดยตรง หรือใช้ local server เช่น

```bash
python -m http.server 8080
```

จากนั้นเปิด `http://localhost:8080`

## คำชี้แจง

เว็บไซต์นี้เป็นต้นแบบเพื่อการศึกษา ไม่ใช่ระบบรับฝากหรือระบบชำระเงินอย่างเป็นทางการ การมีชื่อในทะเบียนไม่ได้แปลว่าสถานีนั้นรับฝากพัสดุ อัตรา เส้นทาง ขนาดสินค้า และกรอบเวลาทั้งหมดต้องตรวจสอบกับสถานีหรือการรถไฟแห่งประเทศไทยก่อนใช้บริการจริง
